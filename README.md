# MJ Events Website

A static, responsive event-company website for MJ Events.

## Structure
- `index.html` — homepage
- `styles.css` — responsive visual system
- `app.js` — navigation, reveal effects and event-detail rendering
- `event.html` / `event.css` — individual event case-study template
- `public/images/` — original event photography and brand assets

## Deployment
This project is configured for Cloudflare Pages as a static site.
- Production branch: `main`
- Build command: none
- Build output directory: `.`
- Preview deployments: enabled for non-production branches

The `redesign/mj-events-v1` branch contains the first redesign preview.
